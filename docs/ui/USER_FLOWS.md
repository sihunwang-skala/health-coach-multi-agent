# 사용자 흐름 (코드 기준)

모든 흐름은 `web/index.html` + `app/server.py`에 **구현된 것**입니다. 실행 화면: `docs/ui/screenshots/`.

## 1. 건강 질문 → 근거 확인
1. 사용자 선택(데모) → 홈에 건강 요약 표시.
2. 질문 입력(또는 예시 chip) → `GET /chat/stream`.
3. 진행 chip: `route` event(경로 + 빠른/정밀 경로) → 단계별 chip(검색어 만들기, 논문 검색, 논문 읽기, 근거 확인, 안전 규칙, 답변 쓰기, 위험한 조언 검사). 색이 아니라 글로 표시.
4. `done` → 답변 + `[1] [2]` 버튼 + 사용한 논문 링크 + 안전 문구.
5. `[n]` 누르면 근거 패널(desktop: 오른쪽 420px / 900px 이하: bottom sheet): 문서 ID, chunk, 이 답변 문장(한국어), 논문 원문(영어, 조각 옅게 + 뒷받침 문장 진하게), 근거 메모, PMC 링크. 위치 정보가 없으면 "위치 정보가 없어 발췌문과 링크만 제공" 안내. Esc 또는 ✕로 닫고 눌렀던 버튼으로 focus 복귀.
6. 오류/연결 끊김 → "죄송합니다…" + **다시 시도** 버튼(자동 재연결 없음).

## 2. 응급
- 응급 표현(코드 규칙, LLM 없음) → 화면 위쪽 붉은 배너 `⚠ 응급일 수 있습니다` + **119에 전화** 버튼(`tel:119`) + 대화에 고정 안내문. 붉은색 외에 ⚠ 아이콘과 글자로도 전달.

## 3. 기록
- "내 기록" 펼치기 → 최근 기록, **기록 추가**(입력 → 채팅으로 전송, supervisor가 `log`로 분류), **마지막 기록 삭제**.
- 삭제: supervisor `delete_record` → `interrupt()` → `done.interrupt` → 승인 dialog(취소 / 삭제) → `POST /approve` → 결과 메시지. 승인 전에는 지우지 않음.

## 4. 의료진 상담
- "간호사와 이야기하고 싶어요" → `handoff` route → 안내문 + **의료진 상담 전화(데모 번호)** 버튼. 운영자 화면 알림 목록에 "상담 요청"으로 올라감.

## 5. 설정
- ⚙: 언어(한국어/English), 글자 크기(16~26px), 개인정보 안내. 선호값만 localStorage(대화·건강정보는 저장하지 않음).

## 6. 관리자 (`/admin`, desktop 중심)
- KPI 6개, 하루 메시지·경로 차트, 알림(응급·상담·약 변경·다른 사람 정보) 목록과 "처리 완료로 표시", 사용자별 표(키보드로 열기), 한 명 보기(프로필, 혈당 그래프, 기록, 대화·비용). 30초마다 새로 고침.

## 7. 구현하지 않은 것
- 온보딩 화면(데모 사용자 선택으로 대체), Capacitor 앱, 원문 위치 이동, 본문 token streaming, 논문 원문 번역, 사용자 앱 안의 관리자 기능(의도적으로 제외).
