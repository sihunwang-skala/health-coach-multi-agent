## 2. Architecture (details: `docs/ARCHITECTURE.md`)
```
guard (emergency regex, no LLM) ─┬─ emergency_reply (119 text)
                                 └─ supervisor (LLM router: diet / exercise / diet_exercise / my_data / log / delete_record / med_change / chat)
   diet | exercise | diet_exercise → [Diet Agent ‖ Exercise Agent (compiled subgraphs, as needed) ‖ Safety Agent (rule table, code)]
                                   → writer (LLM) → validate (dangerous-advice rules S1–S9) ─┬─ done
                                                                                             ├─ retry (max 1, 60 s budget) → writer
                                                                                             └─ remove_unsafe (+ rule text first)
   med_change → fixed safety reply · log / my_data / chat → records agent · delete_record → interrupt() (human approval)
```
| Path | Role |
|---|---|
| `coach/graph.py` | supervisor graph assembly (parallel fan-out, joins, HITL checkpointer) |
| `coach/agents/evidence.py` | Diet/Exercise agent subgraph: query chain (4 LLM calls) → MCP search → per-query picker (LCEL batch) → note check; `evidence_node(domain)` |
| `coach/agents/{supervisor,safety_agent,writer,records}.py` | other agents |

## 4. Current results (2026-10-22, GPT-6 Luna, eval/results/metrics_tables.md — every number generated by eval/make_tables.py)
100 messages: 60 health (exercise / diet / diet+exercise, each 10 own-health + 10 general; 97 must-answer points, 98 gold
sentences) + 40 others (my info and records 10, chat 10, safety 10 = emergency 5 + medicine change 5, service and privacy 10).
Four systems: Standard Paper-Search RAG (`before.json`), Health Agentic RAG without safety layer (`agentic_rag.json`,
`eval/run_rag_only.py`), Single-Agent + Health Agentic RAG (`single.json`, `build_single_agent_graph`), Multi-Agent +
Health Agentic RAG (`after.json`).
- Health answer score 75.3% / 73.2% / 88.7% / **91.5%**; gold evidence in context 31.6% / 58.2% / 58.2% / 60.2%;
  answers with a safety problem 8.3% / 10% / 0% / 0%; latency 4.1 / 15.1 / 15.5 / 18.2 s; cost $0.0002 / $0.0025 / $0.0025 / $0.0032.
- Other 40 handled: 57.5% / — / 35.0% / **97.5%**; routing 97/100, personal/general split 60/60.
- **Grader**: Claude Opus 5.5 read every answer (`eval/scores_claude.json`, 1 / 0.75 / 0.5 / 0.25 / 0; `handled` for the 40).
- **Caveats**: one run per system; the same multi-agent run twice moved own-health score 92.7% vs 88.6% (kept as
  `after_v1_no_personal_general_split.json`). The safety checker had false alarms (negations, guideline descriptions) —
  fixed 2026-10-22 with tests; all numbers use the fixed rules.
- To add an item: append it to `eval/questions.json`, run `run_eval.py --ids NEW` (and `--only single`), grade it in
  `eval/scores_claude.json`, then `score.py`, `make_tables.py`, `charts.py`, update README / REPORT.
